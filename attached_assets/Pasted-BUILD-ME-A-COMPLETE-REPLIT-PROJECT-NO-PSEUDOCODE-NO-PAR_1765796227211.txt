GOAL
A Telegram verification bot that:
- Locks down new users immediately (restrict from sending)
- Gives 5 minutes + 3 attempts
- Verification passes ONLY if:
  A) user uploads at least 5 NON-FORWARDED videos related to group subject
  OR

- On fail (3rd attempt) OR timeout: ban user
- Save ALL submissions and outcomes permanently to Supabase
- Admins can change rules without redeploying
- Add manual admin approval buttons + web dashboard

========================
VERIFICATION DETAILS (STRICT)
========================
On new_chat_members:
- create group row if missing
- ensure rules row exists; if missing insert defaults
- restrict user immediately (mute)
- create/replace verification_session
- send welcome message including:
  - subject of group (from groups.subject)
  - requirements
  - time limit and attempts
  - note: forwarded content not accepted

Validation rules:
- Any forwarded message (video or otherwise) is invalid and consumes an attempt
- VIDEO method:
  - accept only msg.video (not animation/gif)
  - track file_id list
  - pass when count >= required_videos
- LINK method:
  - accept only if allow_links true
  - host must be google OR dropbox OR mega
  - must LOOK like a folder link using regex heuristics:
    Google Drive: /drive/folders/<id> or folderview?id=<id>
    Dropbox: /sh/<id>/<token> (treat as folder share)
    MEGA: /folder/<id>#<key> or #F!<id>!<key>
  - reject non-folder links
  - check uniqueness: link cannot already exist in verifications for same group_id
- Any other message is invalid and consumes an attempt

Failure:
- attempts_used reaches max_attempts => ban user, log failure_reason, delete session
- expires_at passed => ban, log failure_reason timeout, delete session

Success:
- unrestrict user (allow sending)
- log verification status verified
- delete session
- send success_message

IMPORTANT: Telegram bots cannot reliably inspect the cloud folder contents without OAuth.
So implement:
- strict host+folder pattern checks
- uniqueness check
- optional manual approval flow for stricter enforcement
